## Intended story (no title cards)

Blueprint → CalibraytAI understands the plan → buildable geometry → foundation → framing → envelope → finished home → CalibraytAI identity.

PLAN → PRICE → CONTRACT → BUILD → MONITOR → LEARN is told **visually**. No animated headlines. No cycling script. No invented tagline. Frame G uses the approved V1 dark logo only (lockup **PLAN • PRICE • BUILD** is part of that mark).

## Locked house (immutable for Opening V1)

Contemporary Ontario / North American 2-storey detached house, attached two-car garage on camera-right, covered front porch camera-left, mixed gable roof, greige horizontal siding, white window trim, navy front door with sidelight, standard white garage door, modest lawn and driveway. Not a mansion, high-rise, commercial, or tiny house.
