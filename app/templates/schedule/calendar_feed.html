Your appointments in Outlook, Google Calendar or Apple Calendar

Your CalibraytAI appointments (the ones for you, the ones you attend, the ones you made for no one in particular, and your personal ones) appear in your own calendar and update by themselves. Make and change appointments here; your calendar shows them.

Nothing is sent anywhere. Your calendar program fetches a private address. Anyone with that address can see your appointments, including personal ones, so keep it to yourself. You can replace it or turn it off at any time.

How to add it

  • Google Calendar (computer): Other calendars → + → From URL → paste the address → Add calendar.
  • Outlook: Add calendar → Subscribe from web (or From internet) → paste the address → Import / Add.
  • Apple Calendar (Mac or iPhone): File → New Calendar Subscription (iPhone: Settings → Calendar → Accounts → Add Subscribed Calendar) → paste the address. Or use the button above.

Google and Outlook check for changes every few hours; Apple Calendar can be set to check every few minutes.
