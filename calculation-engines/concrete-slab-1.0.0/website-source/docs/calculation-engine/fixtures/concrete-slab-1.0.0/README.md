# concrete_slab 1.0.0 fixtures

These JSON files are engine results. They are not the Contract V1 mirror.

The formula and rounding are in [../../concrete-slab-1.0.0.md](../../concrete-slab-1.0.0.md). The 40 ft × 80 ft × 6 in files are a generic base-slab example, not the Speakeasy slab.

`manifest.json` lists the fingerprint of each result file. `handoff-audit-10x8.example.json` is a download wrapper. Its fingerprint is the fingerprint of the inner `calculation_result`, which is the same as `audit-10x8-thickened-edge-metric.json`.
