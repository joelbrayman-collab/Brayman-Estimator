# Request to Darcy — BMR Winchester reference package (PRO Desk)

To check the PRO Desk's quantities and prices against a real BMR job, we need one recent outbuilding quotation
that BMR Winchester actually prepared:

1. **The sketch or drawing** the customer brought (photo or PDF).
2. **BMR's original material takeoff** for it (the list as counted by the store).
3. **The product SKUs and selling units** used on that takeoff (e.g. 2x4x16 SPF, each; steel panel, per lineal foot).
4. **The selling prices** used, with BMR's written permission to load them, and any account discount applied.
5. **The quotation** as given to the customer (total, delivery, HST, validity).
6. **Anything left out** on purpose: trusses quoted by the truss plant, engineering, footings, labour, permits.

Customer name and contact details can be removed. We use the package only to compare quantities and prices; it is
not shown to anyone else, and BMR prices are never used in a demonstration without BMR's permission.
