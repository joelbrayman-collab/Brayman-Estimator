# CalibraytAI — Brayman Installation & Initial Setup Guide

Brayman Construction. 7 October 2026.

This is how the Brayman office is opened and how Ben and the crew start using it. Joel opens the office. Ben does not install the program.

## 1. Joel starts the Mac office

Joel starts the office from the Brayman-Estimator folder:

`flask run --port 5001`

On this Mac, port 5000 is already used by the system. The office uses 5001.

## 2. Ben opens the office

On that same Mac, Ben opens:

`http://127.0.0.1:5001`

If Joel gives a different address, use that address. Do not guess another one. Do not use the website for a real job.

## 3. Ben signs in

The screen says Office sign in. Ben uses the email and password Joel gave him and chooses Sign in.

There is no Create Account button.

## 4. Company information is already configured

The company name, rates, and how Brayman prices work are already in the office. Ben does not set those up. If a company fact looks wrong, Ben tells Joel. Ben does not invent a rate or a margin.

## 5. Joel creates crew logins

Joel creates each crew login and sets the password. Joel gives that person the email and the password.

A crew member does not create their own login. Ben does not create crew logins.

Forgot Password may mention email. Do not wait on that email. Ask Joel to set the password.

## 6. Ben and the crew set up the iPhone browser

The phone uses the office website in the browser. It is not a separate app from the App Store.

1. Joel gives the person the office address and the login he created.
2. On the iPhone, open that address in Safari.
3. Sign in.
4. To keep it on the home screen: Share, then Add to Home Screen. The name can stay Calibrayt.
5. Open it from that icon the next time. Sign in if the phone asks.

## 7. Camera and microphone

When the phone asks for the camera or the microphone, allow them if this person captures photos or speaks a Help question.

Help can be asked by speaking. Speaking a Help question does not change the project, the estimate, or the schedule.

If the phone will not allow the microphone, the person can still type the Help question.

## 8. Field

Field is the same office, opened on the phone or on the Mac.

1. Open Field.
2. Open the project and confirm it. The button is Confirm and Capture, or Confirm for Today.
3. On Capture, save the note, the photo, or the voice that is actually there.
4. Back on the project, open Field Observations and confirm the note is listed.

A field note is evidence. It is not an actual cost.

Today on Field can be printed. That sheet is the same work already on the screen.

## 9. QuickBooks

Calibrayt produces the QuickBooks-ready sheet.

A person types the required information into QuickBooks.

Calibrayt does not send the job to QuickBooks.

## 10. Supplier

Calibrayt generates a job-specific Supplier Estimate Request.

The supplier completes the product and the price.

The sheet comes back to Joel. Joel records the cost Brayman will use.

The supplier does not approve Brayman's cost.

## 11. Contract

Calibrayt uses the active Brayman V1 Ontario contract package. The contract package/version used for the project is recorded in the contract snapshot.

The package is Brayman V1 Interim. It is not marked counsel-approved. Generating a contract does not sign it and does not send a signing link.

If no active package is in force, the contract stays blocked. Do not look for a way around that block. Do not email a signing link.

## 12. Backup

Joel owns backup and recovery.

Ben does not copy the office file, rename it, or restore it. If the office will not open, Ben stops and calls Joel.

## 13. Start the first project

Only after Joel says which job is the real one.

1. If the customer is not already under Clients, add the client.
2. On Home, choose + Start New Project.
3. Enter the project name and the client. Save.
4. Open the project and review the job location.

Do not use an old practice job as the real customer job. Do not delete practice jobs.
